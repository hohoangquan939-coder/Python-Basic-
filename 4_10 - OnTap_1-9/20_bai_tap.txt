## Bài 1 — Phân loại số

**Đề bài:** Nhập vào 1 số nguyên `n`. In ra số đó là số dương, số âm, hay số 0. Nếu là số dương, in thêm số đó là chẵn hay lẻ.

**Input:**
```
Nhap n: 8
```

**Output:**
```
So duong
So chan
```

**Input:**
```
Nhap n: -5
```

**Output:**
```
So am
```

## Bài 2 — Giải phương trình bậc nhất

**Đề bài:** Nhập 2 số thực `a`, `b` của phương trình `ax + b = 0`. Giải và in ra nghiệm.
- Nếu `a == 0` và `b == 0`: in `"Phuong trinh vo so nghiem"`
- Nếu `a == 0` và `b != 0`: in `"Phuong trinh vo nghiem"`
- Ngược lại: in nghiệm `x = -b/a` (làm tròn 2 chữ số thập phân)

**Input:**
```
Nhap a: 2
Nhap b: -10
```

**Output:**
```
Nghiem: x = 5.0
```

## Bài 3 — Tổng các số trong khoảng

**Đề bài:** Nhập 2 số nguyên `a`, `b` (`a <= b`). Tính tổng tất cả số nguyên trong khoảng `[a, b]` chia hết cho 3 hoặc 5.

**Input:**
```
Nhap a: 1
Nhap b: 15
```

**Output:**
```
Tong cac so chia het cho 3 hoac 5: 60
```
*(3,5,6,9,10,12,15 → tổng = 60)*

## Bài 5 — Bảng cửu chương tuỳ chọn

## Bài 8 — Loại bỏ phần tử trùng lặp

## Bài 9 — Quản lý điểm sinh viên (Dict)

**Đề bài:** Cho dict `sinh_vien` có sẵn:
```python
sinh_vien = {"name": "Tran Van A", "toan": 8.5, "ly": 7.0, "hoa": 9.0}
```
Viết function `diem_trung_binh(sv)` tính điểm trung bình 3 môn (làm tròn 2 chữ số), rồi in kết quả kèm xếp loại:
- `>= 8.0`: "Gioi", `>= 6.5`: "Kha", `>= 5.0`: "Trung binh", còn lại: "Yeu"

**Input:** Không có (dict cho sẵn)

**Output:**
```
Sinh vien: Tran Van A
Diem trung binh: 8.17
Xep loai: Gioi
```

## Bài 10 — Tìm kiếm trong danh sách Dict

**Đề bài:** Cho list `products` có sẵn:
```python
products = [
    {"name": "Ban phim", "price": 250000},
    {"name": "Chuot", "price": 150000},
    {"name": "Man hinh", "price": 2500000},
    {"name": "Tai nghe", "price": 350000}
]
```
Nhập vào mức giá `limit`. Viết function `loc_gia(lst, limit)` trả về list tên các sản phẩm có giá **nhỏ hơn hoặc bằng** `limit`.

**Input:**
```
Nhap muc gia toi da: 300000
```

**Output:**
```
San pham phu hop: ['Ban phim', 'Chuot']
```

## Bài 18 — Máy tính chia an toàn

**Đề bài:** Viết function `chia_an_toan(a, b)` thực hiện phép chia `a/b` có xử lý lỗi:
- Nếu `b == 0`: trả về chuỗi `"Khong the chia cho 0"`
- Nếu `a` hoặc `b` không phải số (truyền vào kiểu khác): trả về chuỗi `"Du lieu khong hop le"`
- Ngược lại: trả về kết quả phép chia (làm tròn 2 chữ số)

Test với 3 trường hợp: `chia_an_toan(10, 2)`, `chia_an_toan(5, 0)`, `chia_an_toan(10, "a")`

**Input:** Không có (test case cho sẵn)

**Output:**
```
10 / 2 = 5.0
5 / 0 = Khong the chia cho 0
10 / a = Du lieu khong hop le
```

## Bài 19 — Quản lý kho hàng tổng hợp

**Đề bài:** Cho list `kho` có sẵn:
```python
kho = [
    {"ten": "Gao", "soluong": 50, "gia": 15000},
    {"ten": "Duong", "soluong": 0, "gia": 20000},
    {"ten": "Muoi", "soluong": 30, "gia": 5000}
]
```
Viết chương trình:
1. Function `tong_gia_tri(kho)` — tính tổng giá trị toàn bộ kho (số lượng × giá)
2. Function `hang_het(kho)` — trả về list tên các mặt hàng có `soluong == 0`
3. In tổng giá trị kho và danh sách hàng hết, ghi danh sách hàng hết vào file `het_hang.txt`

**Input:** Không có (list cho sẵn)

**Output:**
```
Tong gia tri kho: 1050000
Hang het: ['Duong']
Da ghi vao file het_hang.txt
```

## Bài 20 — Chương trình tổng hợp: Quản lý điểm thi có lưu file

**Đề bài:** Viết chương trình hoàn chỉnh:
1. Cho người dùng nhập liên tục: tên sinh viên và điểm thi (gõ "end" ở tên để dừng)
2. Xử lý lỗi nếu điểm nhập không phải số (yêu cầu nhập lại điểm đó)
3. Xử lý lỗi nếu điểm ngoài khoảng 0-10 (yêu cầu nhập lại)
4. Sau khi nhập xong, tính điểm trung bình cả lớp
5. Phân loại từng sinh viên: `>=8`: Gioi, `>=6.5`: Kha, `>=5`: Trung binh, còn lại: Yeu
6. Ghi toàn bộ kết quả (tên, điểm, xếp loại) vào file `ketqua.txt`
7. In ra sinh viên có điểm cao nhất

**Input:**
```
Nhap ten (hoac 'end'): An
Nhap diem: 8.5
Nhap ten (hoac 'end'): Binh
Nhap diem: abc
Loi: diem phai la so!
Nhap diem: 15
Loi: diem phai trong khoang 0-10!
Nhap diem: 6.0
Nhap ten (hoac 'end'): end
```

**Output:**
```
Diem trung binh ca lop: 7.25
Da ghi ket qua vao file ketqua.txt
Sinh vien cao nhat: An - 8.5 diem - Gioi
```
